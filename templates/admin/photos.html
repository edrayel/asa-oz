Set up Google Photos

Pick photos from your Google Photos library and import them into the media library, where they can be used anywhere the CMS accepts an image.

  1. Enable the Google Photos Picker API in your Cloud project.
  2. Add the photospicker.mediaitems.readonly scope to the OAuth consent screen.
  3. Run python authorize_google.py --scopes photos once and approve access.
  4. Point GOOGLE_PHOTOS_CREDENTIALS at the token file it writes and restart the app.

The old Library API scopes (photoslibrary.readonly and friends) were removed on 1 April 2025, so browsing the whole library server-side is no longer possible — the Picker API is the only supported route.
